Project Overview:

FitTrack is a frontend web application designed to help users track workout routines, log completed exercises, and analyze their physical activity metrics over time. The system features a modern, responsive user interface built with HTML5, Tailwind CSS, and React, alongside dynamic data handling to simulate a real-world athletic platform.
